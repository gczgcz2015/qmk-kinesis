# 接线说明：YD-RP2040 右主端与右侧 PMW3360

完整逐键图见 [wiring-layout.svg](wiring-layout.svg)。

## 材料

- YD-RP2040 × 2
- MX 兼容开关 × 81
- 1N4148 穿孔二极管 × 81
- 三芯 TRS 插座 × 2
- 三芯 TRS 公对公线 × 1
- Ogen Lite V1.3 / PMW3360 模块 × 1
- 与右侧外壳匹配的轨迹球和支撑结构 × 1
- 26–28 AWG 单芯线：矩阵行列
- 24–28 AWG 多芯软线：控制器、TRS 和 Ogen Lite

建议先焊完并用万用表检查矩阵，再连接开发板、TRS 和轨迹球。

## 总体结构

固件使用每侧 6 行 × 9 列的统一逻辑矩阵。左侧只使用 C0–C6，C7/C8 以
`NO_PIN` 补齐；右侧使用全部九列。QMK 将右侧本地行 `R0..R5` 映射为全局行
`6..11`。

```text
                                      电脑 USB
                                          │
                                          ▼
左 YD-RP2040（从端）── TRS ── 右 YD-RP2040（主端）
       │                                  │
左 32 主键 + 6 拇指键              右 37 主键 + 6 拇指键
                                          │
                                  Ogen Lite / PMW3360
```

两侧刷入同一个 UF2，正常使用只连接右侧 USB。

## YD-RP2040 矩阵引脚

行引脚两侧相同：

| 矩阵行 | 左侧 | 右侧 |
|---|---|---|
| R0 | GP14 | GP14 |
| R1 | GP15 | GP15 |
| R2 | GP26 | GP26 |
| R3 | GP27 | GP27 |
| R4 | GP28 | GP28 |
| R5 / 拇指区 | GP29 | GP29 |

列引脚：

| 矩阵列 | 左侧 | 右侧 |
|---|---|---|
| C0 | GP2 | GP2 |
| C1 | GP3 | GP3 |
| C2 | GP4 | GP4 |
| C3 | GP5 | GP5 |
| C4 | GP6 | GP6 |
| C5 | GP7 | GP7 |
| C6 | GP8 | GP8 |
| C7 | 不接 / `NO_PIN` | GP9 |
| C8 | 不接 / `NO_PIN` | GP10 |

分体数据使用两侧 `GP0`。固件避开板载 WS2812 `GP23`、用户按钮 `GP24` 和
LED `GP25`。

## 矩阵位置

### 左侧

左侧完全沿用仓库 `main` 分支的实体布局：32 个主键和 6 个拇指键。

```text
       C0 C1 C2 C3 C4 C5 C6 C7 C8
R0      ○  ○  ○  ○  ○  ○  ○  —  —
R1      ○  ○  ○  ○  ○  ○  ○  —  —
R2      ○  ○  ○  ○  ○  ○  ○  —  —
R3      ○  ○  ○  ○  ○  ○  —  —  —
R4      ○  ○  ○  ○  ○  —  —  —  —
R5      —  ○  ○  ○  ○  ○  ○  —  —   拇指区
```

左侧拇指区使用 `R5/C1..C6`。默认键位：

```text
                 C4 Left Ctrl   C6 Left Alt
C1 Backspace 2u  C2 Delete 2u   C5 Home
                                C3 End
```

### 右侧

右侧主键从佩戴者俯视角度由左到右编号 C0–C8，各列键数为
`4 / 2 / 2 / 4 / 5 / 5 / 5 / 5 / 5`。C1/C2 从 R0 开始。

```text
       C0 C1 C2 C3 C4 C5 C6 C7 C8
R0      ○  ○  ○  ○  ○  ○  ○  ○  ○
R1      ○  ○  ○  ○  ○  ○  ○  ○  ○
R2      ○  —  —  ○  ○  ○  ○  ○  ○
R3      ○  —  —  ○  ○  ○  ○  ○  ○
R4      —  —  —  —  ○  ○  ○  ○  ○
R5      —  ○  ○  ○  ○  ○  ○  —  —   拇指区
```

五个新增主键的默认功能：

```text
       C0          C1          C2
R0   Keypad       CPI-        CPI+
R1     Fn       Mouse Left  Mouse Right
R2  Nav/Media      —           —
R3 Mouse Middle    —           —
```

右侧其余 32 个主键保持 `main` 分支中的相对位置与默认功能。

右侧拇指区使用 `R5/C1..C6`，保持原六键几何：

```text
C6 GUI/Win       C4 Right Ctrl
C5 Page Up       C2 Enter 2u    C1 Space 2u
C3 Page Down
```

Vial 中的纵向 2u 只代表键帽外观。每个位置仍然只使用一个开关、一颗二极管和一个
矩阵交点。

## 单个开关和二极管

固件使用 `COL2ROW`。每颗二极管的黑色带环端必须朝行线：

```text
列线 Cn ── 开关 ── 二极管无环端 ──|带环端|── 行线 Rn
```

焊接步骤：

1. 开关一只焊脚连接所属列线。
2. 另一只焊脚连接 1N4148 无环端。
3. 二极管黑色带环端连接所属行线。
4. 同列开关焊脚相连；同行二极管带环端相连。
5. 行列交叉处绝缘，不直接相连。

## 右侧 Ogen Lite / PMW3360

Ogen Lite 连接右侧 YD-RP2040：

| Ogen Lite 丝印 | 右侧 YD-RP2040 |
|---|---|
| VCC | 3V3 |
| GND | GND |
| SCL | GP18 / SPI0 SCK |
| MOS | GP19 / SPI0 MOSI |
| MIS | GP20 / SPI0 MISO |
| SS | GP21 / CS |
| MOT | 不接 |
| RES | 不接 |

Ogen 丝印 `UP` 朝键盘顶部。轨迹球只输出光标 X/Y，不实现滚动模式。默认
`1600 CPI`，Vial 的 User 分类可分配 `CPI-`、`CPI+`：

```text
100 → 200 → 300 → 400 → 500 → 600 → 700 → 800 →
900 → 1000 → 1100 → 1200 → 1300 → 1400 → 1500 → 1600 →
1700 → 1800 → 1900 → 2000 → 2100 → 2200 → 2300 → 2400 →
2500 → 2600 → 2700 → 2800 → 2900 → 3000 → 3100 → 3200 CPI
```

达到上下限后停止；档位存入 EEPROM。执行 EEPROM Reset 时恢复 1600 CPI。

Ogen Lite 没有 5V 电平转换，`VCC` 绝不能接 `Vin`、`Vout` 或 TRS Ring。

## TRS 数据与供电

| TRS 触点 | 右侧主端 | 左侧从端 |
|---|---|---|
| Tip（尖端） | GP0 | GP0 |
| Ring（中环） | Vout | Vin |
| Sleeve（尾套） | GND | GND |

数据是 RP2040 PIO 半双工连接，不需要 TX/RX 交叉或额外上拉。

YD-RP2040 的 `Vout` 与 `Vin` 不是可以随意互换的同名 5V 引脚。本设计固定右侧
为 USB 主端：右侧从 USB 获得电源，经 `Vout` 和 TRS Ring 给左侧 `Vin` 供电。

### TRS 安全要求

TRS 插拔时触点会擦过并可能瞬间短接。必须遵守：

1. 先拔掉右侧 USB。
2. 确认左侧也没有连接 USB。
3. 再插入或拔出 TRS。
4. TRS 插稳后，只连接右侧 USB。
5. 禁止左右同时连接 USB。

## 上电前检查

1. 两侧 3V3、Vin/Vout 与 GND 不短路。
2. 每条行线之间、每条列线之间不短路。
3. 未按键时行线与列线不导通。
4. 按键时仅对应行列通过二极管单向导通。
5. 左侧 C7/C8 没有接到任何 GPIO。
6. TRS Tip、Ring、Sleeve 各自直通，彼此不短路。
7. 确认右 `Vout → Ring → 左 Vin`。
8. Ogen VCC 接 3V3；GP18–GP21 不与电源或地短路。
9. Ogen MOT/RES 悬空。

## 首次调试顺序

1. 不接 TRS，分别给两块 YD-RP2040 刷入同一个 UF2。
2. 两侧断电后插好 TRS。
3. 只给右侧连接 USB。
4. 先逐键验证右侧九列与左右拇指区。
5. 再验证左侧主键区。
6. 滚动轨迹球确认光标 X/Y 方向；`UP` 应朝键盘顶部。
7. 在 Vial 中确认显示 81 键，并从 User 分类测试 `CPI-`、`CPI+`。
8. 调整 CPI 后断电重连，确认档位保持。
9. 若整行失效，检查对应 R 引脚；若整列失效，检查对应 C 引脚。
10. 若左侧全部失效，检查 GP0、GND、右 Vout、左 Vin 和 TRS。
11. 若轨迹球无响应，断电后检查 3V3、GND、GP18–GP21 和 Ogen 丝印。
