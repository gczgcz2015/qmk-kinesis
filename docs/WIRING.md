# 分体 4×6 + 3 与 PMW3360 接线说明

本配置使用两块 Waveshare RP2040-Zero：每侧 24 个主键和 3 个拇指键，右手增加
Ogen Lite V1.3 / PMW3360 轨迹球。左手固定为 USB 主控，右手的矩阵和轨迹球数据
通过 GP0 单线分体连接传回左手。

完整键位、矩阵坐标、行列总线、RGB 顺序和外设引脚见
[wiring-layout.svg](wiring-layout.svg)。Plum Twist 的近实物二极管方向图仍可参考
[plum-twist-diode-orientation.png](plum-twist-diode-orientation.png)。

## 总体结构

```text
电脑 USB
   │
   ▼
左 RP2040-Zero ─── TRS：GP0 DATA + 5V + GND ─── 右 RP2040-Zero
   │                                                    │
左 5×6 矩阵                                      右 5×6 矩阵 + PMW3360
   │                                                    │
27 颗 SK6812（GP1）                                27 颗 SK6812（GP1）
```

左右必须刷入同一个 UF2。正常使用只把 USB 接到左手；右手由 TRS 的 5V 供电。

## GPIO 是否够用

RP2040-Zero 的 20 个边缘 GPIO 已经足够，不需要焊背面小焊盘。

| 用途 | 左手 GPIO 数 | 右手 GPIO 数 |
|---|---:|---:|
| 5 行 + 6 列矩阵 | 11 | 11 |
| RGB DATA | 1 | 1 |
| 分体 DATA | 1 | 1 |
| 指针外设 | 0 | 4 |
| 合计 | 13 | 17 |

左手 GP9–GP13、GP28、GP29 均空闲。右手 GP13 位于轨迹球引脚区域但保持预留；不要
把左右两块板的空闲 GPIO 互连。

## 两侧通用矩阵与 RGB 引脚

| 功能 | RP2040-Zero | 功能 | RP2040-Zero |
|---|---|---|---|
| 行 R0 | GP14 | 列 C0 | GP2 |
| 行 R1 | GP15 | 列 C1 | GP3 |
| 行 R2 | GP26 | 列 C2 | GP4 |
| 行 R3 | GP27 | 列 C3 | GP5 |
| 行 R4 / 拇指区 | GP8 | 列 C4 | GP6 |
| RGB DATA | GP1 | 列 C5 | GP7 |
| TRS DATA | GP0 |  |  |

主键区使用本地 `R0..R3 × C0..C5`。拇指区复用本地 R4：

```text
左手主键：R0..R3 / C0..C5       右手主键：R0..R3 / C0..C5
左手拇指：R4C3 R4C4 R4C5        右手拇指：R4C0 R4C1 R4C2
```

QMK 将右手本地 R0..R4 映射为全局矩阵行 5..9，因此 Vial 中的右手拇指键坐标是
`9,0`、`9,1`、`9,2`。

## Plum Twist 二极管与矩阵总线

固件使用 `ROW2COL`：

```text
行 Rn → 开关 → 二极管 A（无条纹）→ K（条纹）→ 列 Cn
```

以 Plum Twist 的热插拔座/焊盘面观察，D1 条纹 K 朝中央开关孔。每块 PCB 的 `R`
焊盘接所属蓝色行线，`C` 焊盘接所属黄色列线。行列交叉处只交叉、不焊接，必须绝缘。
不要把固件改成 `COL2ROW`。

每侧焊接顺序建议是：先六条列线，再五条行线；每完成一行就用万用表确认未按键时
行列不导通、按键后只在对应交点单向导通。

## 两条逐键 RGB 链

两侧各有一条独立的 27 颗 SK6812 灯链，数据都从该侧 GP1 开始。每侧按主键区逐行
蛇形，最后接三个拇指键：

```text
本地行       C0  C1  C2  C3  C4  C5
R0 →          0   1   2   3   4   5
R1 ←         11  10   9   8   7   6
R2 →         12  13  14  15  16  17
R3 ←         23  22  21  20  19  18
左 R4 →       —   —   —  24  25  26
右 R4 →      24  25  26   —   —   —
```

右侧在 QMK 中显示为全局 LED27..53，但右侧物理第一颗仍是该侧 GP1 直接连接的第一颗。

```text
GP1 → 220–470 Ω → 第一颗 I
前一颗 O → 下一颗 I
每侧末颗 O 悬空
```

每侧 27 块 PCB 的 `+` 并联到该侧 3V3，`−` 并联到该侧 GND；不要串联电源，也不要
把所有 I/O 并联。建议每侧灯链入口在 3V3 与 GND 之间并联 100–470 µF 电容。
固件最大亮度限制为 `32/255`，不要在直接使用板载 3.3 V 稳压器时移除该限制。

## 左手空闲引脚

左手不再连接 Joy-Con 或轨迹球。GP9–GP13、GP28、GP29 保持悬空即可，不要接 3V3
或 GND。固件也不再启用 ADC 驱动或摇杆扫描，Vial 仅保留 Layer 0–3。

## 右手 PMW3360：GP9–GP13 区域

固件使用 RP2040 的 SPI1。实际通信使用 GP9..GP12，GP13 预留给未来的 MOTION 信号，
当前 QMK PMW3360 驱动不需要连接它。

| Ogen / PMW3360 | 右 RP2040-Zero | 说明 |
|---|---|---|
| CS / NCS | GP9 | 片选 |
| SCLK / CLK | GP10 | SPI 时钟 |
| MOSI | GP11 | 主控发往传感器 |
| MISO | GP12 | 传感器发往主控 |
| MOTION（如果模块有） | 不连接，GP13 预留 | 当前固件不用 |
| VCC | 3V3 | 禁止接 5V |
| GND | GND | 共地 |

PMW3360 必须安装匹配透镜，传感器/透镜上的透明运输保护膜必须撕掉。先确认传感器、
透镜和球的高度正确，再判断代码或焊接问题。

方向配置沿用已经测试正确的 `ROTATION_90 + INVERT_Y`。默认 1600 CPI，可选档位是：

```text
100 → 200 → 400 → 800 → 1200 → 1600 → 2400 → 3200 CPI
```

按住左手中间拇指 Fn，再按右手前两个拇指键，分别执行 CPI−、CPI+。当前档位写入
左手主控 EEPROM。Nav/Mouse 层的右手前两个拇指键是鼠标左键和右键，右手 N 位置
是鼠标中键；这些都可在 Vial 中修改。

## TRS 分体接线

| TRS 触点 | 左侧 | 右侧 |
|---|---|---|
| Tip（尖端） | GP0 | GP0 |
| Ring（中环） | 5V | 5V |
| Sleeve（尾套） | GND | GND |

这是 RP2040 PIO 半双工连接，数据线不交叉，也不需要外接上拉。TRS 插拔时触点会
短暂擦过，因此必须遵守：

1. 拔掉左手 USB，并确认右手没有 USB 供电。
2. 完全断电后插入或拔出 TRS。
3. TRS 插稳后，只给左手接 USB。
4. 禁止两侧同时通过 USB 供电。

## 默认第一层

```text
左手                                      右手
=       1       2       3       4       5       6       7       8       9       0       -
Tab     Q       W       E       R       T       Y       U       I       O       P       \
Esc     A       S       D       F       G       H       J       K       L       ;       '
LShift  Z       X       C       V       B       N       M       ,       .       /       RShift
                    LCtrl   Fn   Backspace       Enter   Space   Nav/Mouse
```

Vial 解锁组合是左手 Esc（2,0）+ 右手 Enter（9,0）。由于矩阵尺寸、引脚分配和动态
层数都已改变，从旧固件第一次升级时会把动态键位恢复为本固件默认值；之后 Vial 修改
会正常持久保存。

## 刷写与首次测试

1. 左右和 TRS 全部断开，分别给两块 RP2040-Zero 刷入同一个 UF2。
2. 两侧完全断电后连接 TRS，只给左手接 USB。
3. 先逐键测试左、右矩阵；整行失效检查对应 R，整列失效检查对应 C。
4. 安装透镜和球后测试轨迹球移动，再测试 Nav/Mouse 层的三个鼠标键。
5. 按 Fn + 右手前两个拇指键确认 CPI 可以上下切换。
6. 打开 Vial，确认 54 个键、四层和两侧 RGB 都正常显示。

上电前务必用万用表确认：3V3/5V/GND 之间无短路、各行列之间无短路、TRS 三个触点
一一对应、PMW3360 VCC 没有接到 5V。
